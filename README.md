# Fadel Hermann SEBGO — academic website

Source for <https://f-h-sebgo.github.io>, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme (MIT licence) and deployed by GitHub Actions on every push to `main`.

## Where to edit

| What | File |
| --- | --- |
| Name, sidebar bio, links (Scholar, ORCID…) | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Home page | `_pages/about.md` |
| Research page | `_pages/research.md` |
| CV | `_pages/cv.md` |
| Publications | one file per paper in `_publications/` (copy `2027-01-01-example-paper.md`) |
| Photo | replace `images/profile.png` |
| PDFs (papers, CV) | upload to `files/` → available at `/files/name.pdf` |
